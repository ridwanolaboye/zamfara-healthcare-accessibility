# Assessing Healthcare Accessibility in Zamfara State, Nigeria

## 1. Project Overview

This project aims to assess access to healthcare facilities across Zamfara State, Nigeria, using ArcGIS Pro. A 5 km buffer analysis will be used to identify communities located within the coverage zones of mapped health facilities and communities that may be underserved.

## 2. Spatial Question

Which communities across the 14 Local Government Areas of Zamfara State are located within 5 km of a mapped health facility, and which communities fall outside the buffer zones?

## 3. Study Area

**Location:** Zamfara State, Nigeria.

**Coverage:** All 14 Local Government Areas (LGAs) of Zamfara State.

## 4. Project Objectives

1. Map health facilities and communities across Zamfara State.
2. Create 5 km buffers around mapped health facilities.
3. Identify communities within and outside the buffer zones.
4. Summarise healthcare coverage by LGA.
5. Produce a final map showing covered and potentially underserved communities.

## 6. Methodology

The project will be conducted using ArcGIS Pro through the following steps:

1. Download the required spatial datasets.
2. Load the datasets into ArcGIS Pro and check their coordinate reference systems.
3. Project the data into a suitable projected coordinate system for distance analysis.
4. Clip the datasets to the Zamfara State boundary.
5. Create 5 km buffers around the health facility locations.
6. Identify communities inside and outside the buffer zones using spatial analysis.
7. Summarise the number of covered and potentially underserved communities in each LGA.
8. Design and export the final map.

## 7. Expected Results

The project is expected to produce:

1. A map showing health facilities and their 5 km buffer zones.
2. A spatial classification of communities within and outside the buffer zones.
3. A summary table showing coverage across the 14 LGAs.
4. Identification of areas that may require further investigation into healthcare accessibility.

## 8. Limitations

The 5 km buffer measures straight line distance rather than actual road distance or travel time. Communities outside the buffer zones will be considered potentially underserved based on the selected distance threshold. The accuracy of the results depends on the completeness and quality of the available datasets.
