# Week 2 Data Note: Zamfara State Healthcare Accessibility

## Project Overview

This project assesses healthcare accessibility across Zamfara State, Nigeria, using a 5 km buffer analysis in GIS. The aim is to identify communities within 5 km of mapped health facilities and communities outside the buffer zones that may be underserved.

## Dataset 1: Health Facilities

**Dataset name:** GRID3 Nigeria Health Facilities

**Source:** GRID3 Data Hub

**Source link:** https://data.grid3.org/datasets/827e3638dc204f4b9ddbbd19b00954d6/about

**Study area:** Zamfara State, Nigeria

**Feature count:** 1162.

**Geometry type:** Polygon.
